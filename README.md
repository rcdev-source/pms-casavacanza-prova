# PMS Casa Vacanze

PMS web greenfield per una casa vacanze con quattro camere, progettato per crescere verso più strutture.

## Stack

- Backend: PHP 8.3+, Laravel 12+, Sanctum, queue e scheduler
- Frontend: React, TypeScript strict, Vite, Tailwind CSS, React Router, TanStack Query, React Hook Form e Zod
- Database: MySQL 8 e Redis
- Infrastruttura: Docker Compose e Nginx
- Qualità: Pest/PHPUnit, Vitest, ESLint, TypeScript e GitHub Actions

## Stato

Repository inizializzato. L'implementazione procede nelle sette milestone definite dalla specifica tecnica.
